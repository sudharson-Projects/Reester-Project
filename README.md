
# 🐶 Dog Category Website

## 📌 About the Project

A simple Dog Category Website created using **HTML and CSS only**.

This project is designed to practice HTML block-level and inline elements with basic CSS styling.

## ✨ Features

- Website title and navigation links
- Four dog category images
- Simple and clean layout
- Footer section
- Contact form

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
dog-website/
│
├── index.html
├── style.css
└── images/
    ├── dog1.jpg
    ├── dog2.jpg
    ├── dog3.jpg
    └── dog4.jpg
```
